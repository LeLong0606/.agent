# Generic media production

1. Determine the requested artifact, source material, audience, duration, aspect ratio, brand/style, narration, captions, delivery format, and acceptance criteria.
2. Start with `hyperframes` for HyperFrames work, then load only one matching companion such as product launch, PR-to-video, explainer, captions, talking-head recut, music-to-video, slideshow, motion graphics, or media-use.
3. Confirm required local/runtime dependencies before rendering. Do not install software, use paid generation, publish, or upload without the needed authorization.
4. Build a brief/storyboard when the artifact has multiple scenes or meaningful narrative choices.
5. Verify timing, legibility, safe areas, captions/audio, deterministic rendering, output dimensions, and the final produced file or preview.
